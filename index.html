    给后来的开发者：

    这只是一个简陋的小工具。它只会做一件事：选一种语言，贴一段报错，库里有这条才用中文讲一讲，再附上两个知识点。语言和报错都还在补，功能也简单。

    如果你也喜欢这个小工具，欢迎为其补充和完善！缺的语言可以补上，没覆盖的报错可以补上，觉得不好用的功能也可以直接改。下面是现在这套库怎么加一条报错、怎么加一种语言，文件在同一文件夹的 rules.js，改完保存，关掉这个窗口再打开。

    加一条报错

    1. 打开 rules.js，找到 window.ERROR_RULES。
    2. 在对应语言附近加一条规则。下面的表可以生成一份能直接粘贴的代码。
    3. lang 必须和 ERROR_LANGS 里的名字完全一致。
    4. name 要写报错原文里真实会出现的那一段。test 用来判断对上没有，name 必须能被它匹配到。
    5. 同一句可能对上多条时，更具体的那条把 rank 写成 2，并把 name 写得更长。
    6. 保存后重新打开，选对语言，贴一段真报错，点「翻译」。

    加一种语言

    1. 在 window.ERROR_LANGS 末尾加上语言名。页面上的语言列表读的就是这里。
    2. 按上面的格式，至少加一条 lang 相同的规则。
    3. 行号定位现在页面上不显示，可先不写 window.ERROR_LOCATORS。翻译仍然能用。
