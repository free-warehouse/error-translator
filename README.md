# 报错翻译器

把 HTML、CSS、JavaScript、MySQL、Java、Python、C/C++ 的报错贴进去，用中文说明它是什么意思，并列出相关知识点。

给刚开始写这些语言的人用。认不准的报错不会猜，避免把人带偏。知识点只解释已经对上的概念。

## 怎么用

下载或解压之后，双击一次 `安装到桌面.bat`。

桌面上会出现「报错翻译器」。以后点这个图标，它会像一个小程序一样打开。不用再进文件夹找网页。

解压出来的文件夹要留着。图标只是入口，文件夹删了就打不开。如果把文件夹挪到了别的地方，再双击一次 `安装到桌面.bat`。

已经在文件夹里时，也可以双击 `打开.bat`。

1. 先在「语言」里选你正在写的那一种。没有自动识别。
2. 可以只贴报错原因那一行，也可以贴整段。
3. 点「翻译」。

右上角的「开发」是给改识别库的人用的。普通使用不用点它。

不用安装别的软件，也不用联网，也不用 API 密钥。电脑里有 Edge 或 Chrome 即可。

## 给开发者

这只是一个简陋的小工具。它只会把选中语言里、库中已经有的报错用中文讲一下。语言和报错都还在补，功能也简单。

欢迎后来的开发者补上缺的语言、没覆盖的报错，以及觉得不好用的功能。页面右上角「开发」里有同样的话，还有操作步骤和一段能粘贴的规则。

加一条报错：在 `rules.js` 的 `window.ERROR_RULES` 里按现有格式加一条。`lang` 要和 `window.ERROR_LANGS` 里的名字一致。`name` 写报错原文里真实会出现的那段，并且要能被 `test` 匹配到。更具体的规则把 `rank` 写成 2。

加一种语言：先把名字加进 `window.ERROR_LANGS`，再加至少一条同名 `lang` 的规则。改完保存，关掉窗口再打开。

## 它会做什么

- 只有你选的语言里出现了明确的报错类型，才给出对应解释和知识点。
- 同一种报错里，更具体的说法优先。例如数组越界不会被说成列表越界，少了分号不会被说成少了冒号。
- 对不上时，不编一个原因。它会说明：已储存的错误里识别不了这条，可能是新类型，也可能是语言选错了。

## 语言

HTML、CSS、JavaScript、MySQL、Java、Python、C/C++。
