# 报错翻译器

把 Java、Python、MySQL、JavaScript、C/C++、HTML、CSS 的报错贴进去，用中文说明它是什么意思、先看哪里，并列出相关知识点。

给刚开始写这些语言的人用。认不准的报错不会猜，避免把人带偏。知识点只解释已经对上的概念。

## 怎么用

双击 `打开.bat`，或者用浏览器打开 `index.html`。

1. 语言可以选「自动识别」，也可以指定一种。
2. 把整段报错贴进框里。
3. 点「翻译」，或按 Ctrl + Enter。

不需要安装，不需要联网，也不需要 API 密钥。

## 它会做什么

- 只有原文里出现了明确的报错类型，才给出对应解释和知识点。
- 你选了 Java，但贴进来的是 Python，它会说明更像哪一种，并按那种解释。
- 同一种报错里，更具体的说法优先。例如数组越界不会被说成列表越界，少了分号不会被说成少了冒号。
- 对不上，或同时像好几种语言时，只留下报错的最后一行，不编一个原因。

## 语言

Java、Python、MySQL、JavaScript、C/C++、HTML、CSS。
